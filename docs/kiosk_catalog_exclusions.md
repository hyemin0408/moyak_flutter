# 키오스크 판매 목록 제외 (2026-11-01)

사용자 요청에 따라 ‘소독용 에탄올 솜 200매’(item_seq `901000012`)를
LiveKioskCart의 상품 로딩 시 제외한다. 전체/카테고리/검색에 노출되지 않으며
새 장바구니에 담을 수 없다. 카탈로그 재로딩 시 해당 ID의 편집 가능한 장바구니
항목은 기존 replaceProducts 동작으로 제거되고 금액이 재계산된다.

기존 주문 복구는 카탈로그 필터보다 먼저 처리하므로 이미 생성된 서버 주문 내역을
임의로 수정하거나 취소하지 않는다. 승인 약품 구매 경로도 변경하지 않는다.
별도 상품인 알콜스왑(200300002)은 유지한다.

이는 Flutter 키오스크의 목록 제외이며 백엔드 DB 삭제/가격/재고 변경은 아니다.
제품 사진 원본과 과거 사진 연결 기록도 보존한다. 서버의 판매 목록 자체에서도
제외하려면 백엔드 담당자가 대상 기기와 판매 정책을 확인해 별도 처리해야 한다.
