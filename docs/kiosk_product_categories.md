# 의약외품 화면 분류 정리 (2026-11-01)

공개 백엔드 `scripts/seed_kiosk_products.py`와 로컬 21종 상품 기록을 대조했다.
서버 상품 조회/주문 요청이나 DB 수정은 실행하지 않았다. 요청으로 제외한 소독용
에탄올 솜 200매(901000012)를 뺀 20종은 아래처럼 하나의 탭에만 배정한다.
이는 앱의 탐색 편의를 위한 분류이며 의약외품/의료기기/화장품의 법적 분류가 아니다.

| 탭 | 상품 |
|---|---|
| 상처/연고 (3종) | 메디폼 H뷰티, 메디폼 하이드로콜로이드 밴드, 알콜스왑 |
| 안대/밴드/기타 (13종) | 대일밴드 표준형·아쿠아뉴·어린이용, KF94·KF80·덴탈 마스크, 의료용 안대, 다목적 렌즈 용액·일회용 렌즈 세정액, 리스테린·가그린, 바세린 오리지널·립테라피 |
| 여성용품 (4종) | 좋은느낌 생리대, 좋은느낌 대형 14매, 좋은느낌 오버나이트 10매, 순수한면 팬티라이너 40매 |

백엔드 시드에서는 구강청결제가 상처/연고, 여성용품이 기타에 들어 있어 앱 표시를
상품 코드 기준으로 보정했다. 보습용 바세린도 기타로 분리한다.
신규 상품은 여성용품 category/badge 또는 생리대·팬티라이너·오버나이트 명칭을
우선 인식하고, 나머지는 서버 상처/연고 분류 또는 기타로 표시해 목록에서 빠지지 않게 한다.

기존 탭 ID(전체 0, 상처 4, 기타 5)는 보존하고 여성용품 ID 6을 추가했다.
개발용 6종 예시도 동일한 기준으로 맞췄다. 전체/검색/장바구니 ID·가격·수량은 유지했다.
실제 서버 상품명·분류·가격·재고는 수정하지 않았다.

렌즈 세정액의 앱 표시 이름은 사용자 요청대로 ‘일회용 렌즈 세정액 10ml x 25개’로
줄였다. 기존 원본 파일명이나 흰 배경 편집본은 바꾸지 않았다.

테스트는 알려진 20종 각각의 단일 분류, 여성용품 검색/탭 전환,
서버 가격·재고·상품 ID 보존, 삭제 상품 제외를 MockClient로 확인한다.
