# 현재 의약외품 화면의 사진 확인 상태

현재 UI는 이후 사용자 요청으로 사진 유무와 관계없이 모든 상품을 같은 기본 아이콘으로
표시한다. `사진 준비 중` 문구도 표시하지 않는다. 아래 목록은 사진 확보 이력이다.

2026-10-26. 실제 실행 중인 의약외품 화면과 공개 백엔드의 scripts/seed_kiosk_products.py를 대조했다.
앞서 확인한 machine_inventory 약품 17종과 이 products 목록 21종은 서로 다른 데이터다.
기존 사진 6개는 유지한다. 추가 15개는 정확한 실물 규격 사진이 확보되지 않아 사진 준비 중으로 표시한다.
사용자 선택: 정확한 상품 사진만 사용하고 없는 것은 사진 준비 중 유지. 같은 브랜드의 다른 규격/제형/제품군 사진으로 대체하지 않는다.
백엔드의 901xxxxxx 값은 시연용 상품 코드이며 식약처 공식 품목 코드가 아니다. 외부 의약품 조회에 넘겨 추정 매칭하지 않는다.
