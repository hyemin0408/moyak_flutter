2026-11-01 최종 추가: 사용자 제공 14번 오버나이트 사진을 연결해 21종 모두 사진 연결 완료.
아래는 과거 작업 기록이며 최신 표시 여부는 fixture와 product_image_catalog.dart를 따른다.

2026-11-01 최신 상태: 11번 새 사진/앱 표시명과 15번 팬티라이너 교체 사진을 반영했다.
의약외품 21종 중 20종 사진 연결, 14번 좋은느낌 오버나이트만 아이콘 유지.
11번 서버 이름/판매 단위는 바꾸지 않았으며 앱 표시 이름만 사용자 요청대로 보정했다.

최신 상태: 12·13·16·17·18번 사진을 추가해 현재 18종 연결.
11번 렌즈 세정액은 제외했고, 14·15번은 파일명과 실제 사진이 달라 확인 중이다.

최신 추가 8~10번: 사용자 지정 바세린 2종·다목적 용액 사진을 연결했다.
현재 사진 표시 13종, 아이콘 유지 8종이다. 사진과 원래 등록 정보의 규격·제조사 차이는
product_image_sources.md에 기록했으며 실제 판매 정보나 DB를 변경하지 않았다.

최신 추가: 사용자 제공 6번 메디폼 밴드(901000004), 7번 소독 솜(901000012) 사진도
연결해 현재 의약외품 10종에 사진을 표시한다. 나머지 11종은 공통 아이콘을 유지한다.

추가 반영: 사용자가 제공한 마스크·알콜스왑·좋은느낌 사진을 지정된 1~3번 상품에
연결했다. 기존 표시 3종과 합해 의약외품 6종에 사진을 표시한다.
이는 사용자가 지정한 사진 매핑이며 등록 제조사/실판매 규격의 검증을 의미하지 않는다.
나머지 신규 15종은 기존 아이콘을 유지한다.

현재 UI는 확인된 사진을 다시 표시한다. 2026-10-31 재검토 후 대일밴드 표준형,
리스테린, 공식몰에서 새로 확보한 메디폼 H뷰티 사진을 연결했다. 다른 항목은 정확한
상품 사진을 확인하기 전까지 공통 아이콘을 유지한다. 아래 표의 기존 에셋은 과거 확보 이력이며
모두가 현재 표시 가능한 정확한 사진이라는 뜻은 아니다.

추가 조사 시 확인이 필요한 항목: 바세린 50g/50ml 구분, 립테라피의 향·종류,
렌즈 용액의 브랜드 내 정확한 제품명·용량, 가그린 레귤러/오리지널 구분,
대일밴드의 방수형·어린이용 실제 포장 수량. 좋은느낌·순수한면의 등록 제조사와
기존 사진의 제조사도 일치하지 않아 데이터 확인 없이 다른 포장을 연결하지 않는다.
확정되지 않은 시연 상품의 모델명을 실제 상품으로 임의 변경하거나 서버 DB를 수정하지 않았다.
