**현재 표시 정책 (2026-10-31):** 의약외품 상품 목록에는 확인 가능한 사진을 다시 표시한다.

상품 코드·제조사·가격·재고 등 서버 데이터는 변경하지 않았다. 기존 파일은 보존했다.
