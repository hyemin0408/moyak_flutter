# 상품 이미지 출처 및 연결 범위

**현재 표시 정책:** 사용자 요청으로 상품 목록 및 일반/승인 장바구니의 모든 상품 사진을
숨기고 동일한 기본 아이콘으로 통일했다. 사진 준비 중 문구도 제거했다.
로고·캐릭터와 상품 데이터는 그대로 유지하며, 아래 에셋/출처 기록은 보존용이다.

**구분 정정:** 아래 추가 15종은 약사 승인용 약품 사진이다. 의약외품 화면에 새로 등록된
15종의 사진 추가가 완료된 것이 아니다. 현재 의약외품 21종의 확인 상태는
[의약외품 사진 목록](otc_product_photo_inventory.md)을 따른다. 정확한 사진이 없는 항목은
사용자 요청대로 `사진 준비 중`을 유지한다.

2026-10-26 기준. 기존 6개 에셋을 유지하고 확인된 약품 15종의 사진을 추가했다.
상품/승인 API에 이미지 URL 필드가 없어 앱에 포함된 원본 사진을 품목 코드(item_seq)로 연결한다.
품목 코드가 없거나 변경된 경우에는 공백만 제거한 정확한 제품명으로만 연결한다. 유사 브랜드·용량·제형으로 추정하지 않는다.
식약처 사진은 포장 사진이 아닌 낱알 식별 사진이다. 포장 사진과 모양이 다르며 실제 배출 포장 단위를 보증하지 않는다.
공식 원본은 편집하지 않았으며 출처 표기와 워터마크를 보존한다. 배포 시 각 출처의 이미지 이용 조건은 별도로 확인해야 한다.
